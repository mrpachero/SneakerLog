Setup instructions (one-time, ~5 min)
  1. This file needs to be hosted at a real https:// (or http://localhost) address for Google sign-in to work — it won't work opened directly as a local file. Simplest free option: drop it into a new GitHub repo and enable GitHub Pages, or host it with Netlify Drop.
  2. Go to console.cloud.google.com, create a project, then enable the Google Drive API under "APIs & Services".
  3. Under "APIs & Services → Credentials", create an OAuth Client ID of type "Web application".
  4. Add the exact URL where you're hosting this file (e.g. https://yourname.github.io) under "Authorized JavaScript origins".
  5. Under "OAuth consent screen", add your own Google account as a test user (keeps it private — no Google review needed for personal use).
  6. Copy the generated Client ID and paste it above.

Since this app has no server, Google only issues a short-lived session — you may need to tap "Connect" again every so often (roughly once a day of use). Your data itself only ever leaves your device to go to your own Drive.
